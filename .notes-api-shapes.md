# Luxe Store — Internal API & Data Notes (dev reference)

## tRPC router tree (server/routers.ts)
- `store.categories`, `store.brands`, `store.banners` — public queries, no input
- `store.products` — input: { search?, categoryId?, brandId?, minPrice?, maxPrice?, colors?, sizes?, minRating?, inStock?, isFlashSale?, sortBy, page, pageSize }
- `store.productBySlug` — input: { slug } → returns { product, reviews[] } (product JSON fields parsed: images[], colors[], sizes[], tags[]; rating/reviewCount numbers)
- `store.flashSale` — returns Product[] (isFlashSale && flashSaleEndsAt > now)
- `store.relatedProducts` — input { productId, categoryId, limit }
- `store.reviews` — input { productId } → Review[]
- `store.addReview` — protected, input { productId, rating 1-5, title?, body }
- `store.newsletter` — { email }
- `cart.list/add/update/remove/clear` — protected (add: productId, quantity, size?, color?)
- `checkout.preview` — public input { items: [{ productId, quantity }], couponCode? } → { coupon?, subtotal, discount, shippingCost, tax, total }
- `checkout.create` — protected input: items, customerName, customerEmail?, shippingAddress: { firstName, lastName, address, apartment?, city, state, zip, country, phone? }, couponCode?, paymentMethod, notes? → { orderId, orderNumber, total }
- `orders.myOrders`, `orders.byNumber`({ orderNumber })
- `wishlist.list`, `wishlist.toggle`({ productId }) → boolean (added)
- `admin.*` — adminProcedure: analytics, products, createProduct/updateProduct/deleteProduct, categories/upsertCategory/deleteCategory, brands/upsertBrand/deleteBrand, orders/updateOrderStatus({ id, status enum }), coupons/upsertCoupon/deleteCoupon, banners/upsertBanner/deleteBanner, users/setUserRole
- productFilters zod at top of routers.ts; productInputSchema needs rating as number (transform Stringifies)

## Product model quirks
- rating stored as string "4.5", reviewCount number, price string, compareAtPrice string|null
- images/colors/sizes/tags/stockBySize are JSON text columns; parsed via zod parseJsonField on server; on client check Array.isArray before use
- Address type in drizzle/schema.ts: { firstName, lastName, address, apartment?, city, state, zip, country, phone? }
